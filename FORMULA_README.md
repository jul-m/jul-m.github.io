# Homebrew Tap for jul-m

This repository contains Homebrew formulas maintained by jul-m.

## Available Formulas

### kcl-lsp

KCL Language Server Protocol implementation for the KCL constraint-based language.

**Installation:**
```bash
brew tap jul-m/jul-m.github.io
brew install kcl-lsp
```

**Version:** 0.11.2

**Description:** A constraint-based record & functional language mainly used in configuration and policy scenarios.

**Homepage:** https://kcl-lang.io

## Usage

After installation, the `kcl-language-server` binary will be available in your PATH.

## Supported Platforms

- macOS (Intel and Apple Silicon)
- Linux (x86_64 and ARM64)
